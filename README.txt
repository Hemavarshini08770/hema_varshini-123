DRAGON'S DEN — Website prototype

Includes responsive home page, ecosystem tracks, Launchpad-first messaging, entrepreneurship, talent challenges, community, partnerships, FAQs, contact preview, routed detail pages, and demo login. Unique ember/dragon visual identity with CSS-based 3D motion.

DEPLOY TO VERCEL
1. Extract this ZIP.
2. Import/upload the folder containing index.html and vercel.json into Vercel.
3. Framework preset: Other. Leave Build Command blank; use project root as output directory.
4. Deploy and open the root URL from the latest deployment.

IMPORTANT: Login is demo-only and not connected to authentication. Contact forms do not send/store submissions. Programmes and opportunities are described as planned unless confirmed. Replace policy placeholders and connect secure services before launch.
